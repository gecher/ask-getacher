# Getacher Ashebir: profile

## About Getacher

Getacher Ashebir Yimer is a backend-focused software engineer based in Addis Ababa, Ethiopia. He works as Backend Lead and Full Stack Engineer at Ethiopian Airlines, where he has worked since 2022, and has more than four years of professional experience.

Getacher specialises in designing and developing scalable, secure and high-performance enterprise applications. His core expertise is C#, ASP.NET Core, .NET, RESTful APIs, Clean Architecture, CQRS, Entity Framework Core, SQL Server and enterprise system integration.

He also develops frontends with React and Next.js, and works with AI technologies such as Retrieval-Augmented Generation (RAG), AI-powered applications and intelligent automation.
