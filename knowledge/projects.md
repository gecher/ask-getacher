# Getacher Ashebir: enterprise projects

## eService: enterprise low-code service and workflow platform

Getacher's role: Full Stack Developer.

eService is a centralised low-code platform for digitising enterprise services and business processes across Ethiopian Airlines. Getacher developed and enhanced metadata-driven dynamic form builders, configurable workflow engines, multi-level approvals, business rules and automated notifications, so that new services can be created through configuration instead of new code.

Technologies: C#, ASP.NET Core Web API, React, Next.js, Entity Framework Core, MSSQL, Azure, RESTful APIs.

## AlphaPlus: transit passenger hotel booking system

Getacher's role: Backend Lead.

AlphaPlus is the hotel booking system for Ethiopian Airlines transit passengers. Getacher led the backend of a scalable system serving more than 2,000 transit passengers a day. He designed secure RESTful APIs and background processing jobs for booking, notifications and reporting, and reduced booking errors by 40% through workflow optimisation, improving system reliability.

Technologies: C#, ASP.NET Core Web API, Entity Framework Core, MSSQL, Azure, RESTful APIs, Azure DevOps.

## eProcurement system for Ethiopian Airlines

Getacher's role: Backend Engineer and UI Developer.

An enterprise procurement platform. Getacher built end-to-end procurement workflows, including purchase requests, approvals and supplier management. He integrated asynchronous messaging with RabbitMQ for reliable communication between enterprise systems, and enabled real-time integration with finance and inventory systems, supporting more than 200 suppliers.

Technologies: C#, ASP.NET Core, MSSQL, Entity Framework Core, RabbitMQ.

## Medical management system for Ethiopian Airlines

Getacher's role: Backend Lead.

Getacher architected a modular backend for managing medical records, appointments and notifications for more than 17,000 Ethiopian Airlines employees. He ensured high availability and compliance for healthcare data, and used a CQRS-based design with MediatR for scalability and maintainability.

Technologies: C#, ASP.NET Core, MSSQL, CQRS, MediatR, Azure DevOps.

## Ethiopian Civil Aviation Authority eService system

Getacher's role: Backend Engineer and System Developer.

A low-code e-service platform for civil aviation operations, including pilot licensing services and crew applications. Getacher designed a dynamic form builder that lets new services be configured without code changes, and implemented a workflow-based approval engine with Power Automate and SharePoint for multi-level approvals and document routing. Digitising manual aviation workflows into automated e-services improved service processing efficiency.

Technologies: C#, ASP.NET Core, MSSQL, dynamic forms, workflow engine, Power Automate, SharePoint.

## Pilot License Printing System

Technologies: C#, .NET Framework, Windows Forms, MSSQL.
